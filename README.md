# Luminaxe Dashboard

Dashboard interactivo de inmobiliarias con Supabase realtime.

## Características

✅ Tabla interactiva con búsqueda y filtros  
✅ Realtime — cambios sincronizados en tiempo real  
✅ Métricas en vivo  
✅ Panel de detalles  
✅ Responsive design
